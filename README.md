# certification-proyects
user configuration manager 
A simple Python project that allows users to manage application settings through a dictionary.
This project was developed as part of the freeCodeCamp Python certification curriculum.

Features
The program includes four main functions:

Add settings: Adds new key-value pairs while preventing duplicate keys.
Update settings: Updates the value of an existing setting.
Delete settings: Removes a setting from the dictionary.
View settings: Displays all current settings in a formatted output.

Technologies
Python 3

Concepts Practiced
Through this project, I practiced:

Dictionary manipulation.
Functions and parameters.
Tuples and variable unpacking.
Conditional statements (if / else).
For loops and dictionary iteration.
String methods (.lower(), .capitalize()).
F-strings and string concatenation.
Return statements.
Basic input validation and error handling.

Example
settings = {"language": "spanish", "theme": "dark"}
print(view_settings(settings))

Output:
Current User Settings:
Language: spanish
Theme: dark
